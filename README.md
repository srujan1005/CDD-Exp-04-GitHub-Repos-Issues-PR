# CDD Lab Experiment 4: GitHub Repositories, Issues, Forks, Pull Requests and Code Reviews

## Objective
Create GitHub repositories, manage issues, forks, pull requests and code reviews.

## Duration
2 Hours

## Tasks
1. Create a new GitHub repository.
2. Create and manage issues.
3. Fork a repository.
4. Create a pull request from a fork or branch.
5. Perform a code review on a pull request.

## Key Concepts
- Issues for task tracking
- Forks for contribution
- Pull Requests for code changes
- Code review process

## Expected Outcome
A repository with issues, at least one pull request, and a completed code review.
